# PDF 독서 도우미 랜딩페이지

## 목적

현재 구현된 PDF 읽기·문장 선택·페이지 질문·로컬 처리의 가치를 첫 화면에서 이해하고 직접 체험한 뒤 개인 책장으로 진입한다.

## 요구사항

- `/`는 랜딩, 기존 책장은 `/library`로 제공한다. 기존 책 URL과 샘플 리더는 유지한다.
- 기존 책장·리더의 종이색 배경, Pretendard 제목, 작은 탐색 바와 기본 버튼을 유지한다. 랜딩만의 별도 배경색과 과도한 장식을 두지 않는다.
- 표지와 체험은 운영체제·자료구조 등 기술·학습 주제로 구성한다.
- 독창적인 가상 도서 표지와 입체 책 전환을 제공한다. 기존 서비스 표지는 사용하지 않는다.
- 메인페이지에서도 실제 리더처럼 본문을 드래그해 선택 메뉴를 열고, 채팅에 인용을 추가하거나 설명 질문을 바로 보낸다. 페이지 요약은 채팅의 추천 질문 버튼으로 보낸다. 실제 선택 메뉴·채팅 컴포넌트를 재사용하며 임의의 선택 버튼과 요약 탭은 두지 않는다. 미리 작성한 체험 답변임을 명시하고 실제 샘플 리더도 연결한다.
- 랜딩 진입만으로 OCR·AI 모델을 다운로드하거나 책장 저장소를 초기화하지 않는다.
- 카피는 현재 구현된 기능만 소개한다. 검색·RAG·근거 이동, 완벽한 OCR·보안, 저작권 적법성을 보장하지 않는다.
- 키보드 조작, 동작 감소, 320px 모바일, 다크 테마를 지원한다.

## 제외 범위

새 AI 기능, 실제 생성형 모델 기반 랜딩 데모, 회원가입·결제·배포.

## 완료 조건

표지 전환, 체험 상태 변경, 책장 진입·리더 복귀가 동작하고 포맷·린트·타입·단위 테스트·빌드 및 랜딩 E2E가 통과한다. 데스크톱·모바일 브라우저에서 레이아웃을 확인한다.
