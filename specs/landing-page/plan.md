# 구현 계획

- 기존 React Router에 랜딩을 추가하고 실제 리더·책장 경로는 지연 로딩한다.
- 기존 Button·Badge·Separator와 실제 리더의 Thread·추천 질문·선택 메뉴를 조합한다. 선택 메뉴와 추천 질문은 공통 컴포넌트로 옮겨 양쪽에서 사용한다. 테마는 index.css에서 관리하고 책 입체 변환만 CSS로 구현한다.
- 기존 서재와 같은 배경·탐색 바·제목 서체를 쓰고, 체험은 운영체제의 가상 메모리 개념으로 구성한다.
- 표지는 직접 작성한 SVG 타이포그래피·기하학 도형을 사용한다. 체험 본문과 답변도 직접 작성한다.
- 컴포넌트 테스트 실패를 먼저 확인한 뒤 구현하고, E2E로 경로·반응형·실제 조작을 검증한다.
- 기존 책장 E2E 진입 경로와 리더의 책장 복귀 링크를 함께 변경한다.
