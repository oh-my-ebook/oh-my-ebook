# 기본 PDF Reader

## 개요

샘플 PDF를 읽고 페이지를 탐색하며 보기 방식과 표시 크기를 조절할 수 있다. 텍스트 PDF와 스캔 PDF 모두 OCR 없이 표시하고 원본 비율·글꼴·조판을 유지한다. 화면은 상단 툴바, 중앙 본문, 하단 독서 위치 바, 열고 닫거나 너비를 조절할 수 있는 함께 읽기 패널로 구성한다.

## Clarifications

### 제외 범위

- 랜딩페이지, 책장, 사용자 파일 선택·업로드·관리, EPUB.
- OCR, 텍스트 추출·검색·선택 기능, 목차 추출·생성, 북마크 저장, 하이라이트. 목차·책갈피 버튼과 빈 목차 Sheet는 제외 범위에 포함하지 않는다.
- 책 제목·저자·ISBN 자동 추출, 인쇄 쪽수 인식, 가로 페이지 분할.
- AI 실행·RAG·문맥 처리, 근거 위치 이동·강조·복귀, 질문 입력창·추천 질문·답변·근거 카드·노트의 UI와 목업.
- 독서 위치·설정·기록의 영구 저장, 로그인, 서버 저장.
- 별도 설정 메뉴, 사용자 회전 도구, 연속 페이지 스크롤 모드.
- 암호 입력·해제, PDF 원문 텍스트의 보조 기술 읽기 지원.

## 기능 요구사항

**현재 페이지**는 사용자가 선택한 PDF 페이지이며, 나란히 표시된 두 페이지 중 두 번째 페이지일 수도 있다.

### 진입과 화면 구성

- **FR-001**: 샘플 PDF가 열린 Reader로 직접 진입한다. 초기 상태는 첫 페이지, 한 페이지 보기, 높이 맞춤, 보조 패널 닫힘이다.
- **FR-002**: 실제 PDF의 이미지·텍스트·배치를 원본 비율로 표시한다. OCR이나 본문 텍스트 유무에 의존하지 않으며 HTML 샘플 본문으로 대체하지 않는다.
- **FR-003**: 상단에는 돌아가기, 목차, 책갈피, 문서명, 보기 전환, 테마 전환, 함께 읽기 패널 열기·닫기를 둔다. 하단에는 첫·이전·다음·마지막 페이지 이동, 현재·전체 페이지 수, 페이지 슬라이더, 확대·축소·확대율·높이 맞춤을 둔다.
- **FR-004**: 문서명은 지정한 샘플 제목을 쓰고, 없으면 파일명을 쓴다. 메타데이터나 표지에서 자동 추출하지 않는다.
- **FR-005**: 표지를 포함한 PDF 첫 페이지를 1로 센다. 단독 표시는 `3 / 10`, 두 페이지 표시는 `3–4 / 10`처럼 구분하며 인쇄 쪽수로 바꾸지 않는다.

### 페이지 방향과 보기 방식

- **FR-006**: PDF에 기록된 회전을 적용한 페이지 폭이 높이보다 크면 가로, 나머지는 세로로 취급한다. 정사각형은 세로 규칙을 따르고 스캔 이미지의 내용이나 방향을 추론하지 않는다.
- **FR-007**: 가로 페이지는 보기 설정과 관계없이 한 장만 펼침면 영역에 표시한다. 이미지를 나누거나 PDF 페이지 수를 변경하지 않는다.
- **FR-008**: 세로 페이지는 한 페이지·두 페이지 보기를 지원한다. 두 페이지 보기에서는 파일 처음부터 연속된 세로 페이지를 최대 두 장씩 나란히 표시한다. 가로 페이지와 홀로 남은 세로 페이지는 단독 표시하며 표지도 같은 규칙을 따른다.
- **FR-009**: 두 페이지는 파일 순서대로 왼쪽부터 표시한다. 가로 페이지를 건너뛰어 세로 페이지를 묶거나, 마지막 한 장 옆에 가상 페이지를 만들지 않는다.
- **FR-010**: 보기 전환, 화면 크기 변경, 패널 열기·닫기 후에도 현재 페이지를 화면에 포함한다. 슬라이더는 선택한 페이지를 유지하고, 첫·이전·다음·마지막 페이지 이동 후 화면에 먼저 표시되는 페이지를 현재 페이지로 삼는다.

### 페이지 탐색

- **FR-011**: 이전·다음은 현재 보기 방식에서 바로 앞이나 뒤에 표시할 페이지로 이동하고 본문 상단을 표시한다. 더 이전이나 다음에 표시할 페이지가 없으면 해당 버튼을 비활성화한다. 키보드 `←`·`→`로도 같은 이전·다음 이동을 하고, 키를 누르고 있으면 반복 입력마다 계속 이동한다. 글자 입력·슬라이더·구분선·보기 방식처럼 화살표를 직접 쓰는 조작부에 포커스가 있거나 Sheet가 열려 있으면 페이지를 넘기지 않는다.
- **FR-012**: PageNavigator는 슬라이더로 선택한 현재 페이지와 전체 페이지 수를 수정할 수 없는 일반 텍스트로 `4 / 10`처럼 표시하고 접근 가능한 이름을 `페이지 위치`로 제공한다. 두 페이지 보기의 본문은 표시 중인 펼침면 범위를 `3–4 / 10`처럼 별도로 표시하고 접근 가능한 이름을 `펼침면 범위`로 제공한다. 첫·이전 페이지와 다음·마지막 페이지는 서로 다른 아이콘과 접근 가능한 이름으로 구분한다.
- **FR-013**: 슬라이더는 PDF 페이지 단위로 선택하고 트랙 클릭·마우스 드래그·키보드로 조작할 수 있어야 한다. 드래그 중에는 선택 위치와 페이지 텍스트를 갱신하고 포인터를 놓을 때 본문 페이지를 변경한다. 첫 표시에는 thumb 위치 보정 애니메이션이 나타나지 않아야 한다. 선택한 페이지가 화면에 포함되도록 표시하며, 한 페이지 문서에서는 이동 조작을 비활성화하고 `1 / 1`을 표시한다.

### 크기 조절과 패널

- **FR-014**: 수동 확대·축소는 현재 화면에 표시된 모든 페이지에 같은 배율을 적용하고 높이 맞춤을 해제한다. 페이지 이동·화면 크기·패널 상태가 바뀌어도 배율을 유지한다. 배율 변경은 200ms 동안 자연스럽게 전환하되 동작 감소를 선호하면 즉시 반영한다. 확대된 본문은 읽기 영역 안에서 가로·세로 스크롤할 수 있어야 한다.
- **FR-015**: 높이 맞춤은 원본 비율을 유지하면서 한 페이지 또는 나란히 표시된 두 페이지 전체가 읽기 영역의 가용 높이와 너비 안에 들어오는 최대 배율을 적용한다. 높이에 맞춘 폭이 가용 너비를 초과하면 너비에 맞게 추가로 축소하고, 폭이 남으면 페이지를 가로 중앙에 배치한다. 활성 상태에서는 페이지·보기 방식·창 크기·패널 상태 변경에 따라 다시 맞추며 가로·세로 스크롤을 만들지 않는다.
- **FR-016**: 화면 폭 1024px 이상이면 읽기 영역의 가용 폭과 관계없이 세로 두 페이지 보기를 적용한다. 패널을 열어 읽기 영역이 좁아지면 FR-015에 따라 두 페이지를 너비에 맞게 축소한다. 화면 폭이 부족하면 보기 방식 조작과 옆 구분선을 숨기고 한 페이지를 표시한다. 두 페이지 보기 중 공간이 부족해지면 간단한 toast로 변경을 안내한다. 가로 페이지나 공간 부족 때문에 단독 표시하더라도 두 페이지 보기 선호는 유지하고, 적용 가능한 상태에서 복원한다.
- **FR-017**: 함께 읽기 패널의 열기·닫기를 제공한다. 화면 폭 1024px 이상에서는 본문 옆에 표시하고 구분선을 키보드와 포인터로 움직여 너비를 조절할 수 있어야 한다. 화면 폭이 1024px 미만이면 본문 위에 열리는 오른쪽 Sheet로 표시한다.

### 상태와 접근성

- **FR-018**: 로딩 상태를 표시하고 사용할 수 없는 독서 조작을 비활성화한다. 불러오기·페이지 표시 실패는 오류와 해당 작업의 재시도를 제공한다. 이전 페이지를 새 페이지로 표시한 것처럼 안내하거나, 늦게 끝난 이전 요청이 마지막 선택을 덮어쓰지 않아야 한다. 손상·암호 필요 문서는 오류로 안내하고 암호 입력 기능은 제공하지 않는다.
- **FR-019**: 조작부에 접근 가능한 이름, 키보드 조작, 보이는 포커스를 제공한다. 패널을 닫으면 열기 버튼으로 포커스를 복원하고, 로딩·오류는 보조 기술로도 확인할 수 있어야 한다.
- **FR-020**: 320px 화면 폭과 브라우저 200% 확대에서 조작부가 잘리거나 겹치지 않아야 한다. 긴 문서명은 조작부를 밀어내지 않으며 전체 이름을 확인할 수 있어야 한다. 본문 스크롤과 관계없이 툴바·하단 탐색을 사용할 수 있어야 한다.
- **FR-021**: 새로고침하면 FR-001의 초기 상태로 시작한다. 독서 상태 복원을 위한 별도 영구 저장은 하지 않는다.
- **FR-022**: 상단 테마 버튼으로 라이트·다크 모드를 전환한다. PDF Canvas의 원본 색은 반전하지 않고 Reader 배경·툴바·패널·조작부에 의미 색상 토큰을 적용한다.
- **FR-023**: 목차 버튼은 빈 목차 패널을 연다. 넓은 화면에서는 헤더 없이 읽기 영역 왼쪽에 폭 280px로 붙어 본문을 덮지 않고, 목차 버튼으로 여닫는다. 좁은 화면에서는 제목과 닫기 조작이 있는 왼쪽 Sheet로 열고, 닫으면 목차 버튼으로 포커스를 돌린다. 목차 항목을 임의로 만들지 않는다. 돌아가기·책갈피처럼 아직 연결할 기능이 없는 버튼은 누를 수 있지만 상태를 바꾸거나 안내를 표시하지 않는다.

## 사용자 시나리오

1. **책 읽기**: Reader에 진입하면 로딩 후 샘플 첫 페이지가 보인다. 첫·이전·다음·마지막 이동과 슬라이더로 원하는 페이지를 읽는다. 텍스트가 없는 스캔 PDF도 같은 흐름을 따른다.
2. **보기 전환**: 넓은 화면에서 세로 PDF의 3페이지를 읽다가 두 페이지 보기를 선택하면 3–4페이지가 보인다. 다음은 5–6페이지, 이전은 다시 3–4페이지다. 슬라이더로 4페이지를 선택한 뒤 한 페이지 보기로 전환하면 4페이지가 남는다.
3. **혼합 문서 읽기**: 방향이 세로·세로·가로·세로·세로인 문서는 두 페이지 보기에서 `[1, 2] → [3] → [4, 5]`로 이동한다. 역방향에서도 같은 페이지를 함께 표시하며 세로·가로·세로는 모두 단독 표시한다. 세로 5장짜리 문서의 마지막은 `[5]`다.
4. **크기 조절**: 작은 글씨를 확대해 읽다가 높이 맞춤을 선택하면 현재 화면에 표시된 모든 페이지가 읽기 영역 안에 들어오고 폭이 남을 때 가로 중앙에 놓인다. 창이나 패널 크기가 바뀌면 다시 맞추며, 수동 배율에서는 본문을 스크롤해 가장자리까지 읽는다.
5. **좁은 화면으로 전환**: 두 페이지를 읽다가 공간이 부족해지면 현재 페이지 한 장만 보인다. 충분히 넓어지면 두 페이지 보기로 돌아온다. 가로 페이지는 화면 폭과 관계없이 분할하지 않는다.
6. **실패에서 복구**: PDF 불러오기나 페이지 표시가 실패하면 재시도할 수 있고, 성공하면 본문과 위치 정보가 일치한다.
7. **독서 화면 조절**: 상단에서 다크 모드와 함께 읽기 패널을 켠다. 넓은 화면에서는 패널 구분선을 움직여 본문과 채팅 폭을 바꾸고, 좁은 화면에서는 같은 패널을 Sheet로 연다. 목차를 열면 항목이 없는 패널만 표시된다.

## 완료 기준

- **SC-001**: 텍스트 PDF와 OCR 텍스트가 없는 스캔 PDF 각각에서 첫 페이지 표시, 첫·이전·다음·마지막 이동, 슬라이더, 확대·축소, 높이 맞춤이 동작한다. 높이 맞춤에서는 현재 화면에 표시된 모든 페이지가 한 화면에 들어오고 폭이 남으면 가로 중앙에 놓인다.
- **SC-002**: 세로 전용·가로 전용·혼합·세로 홀수 장 샘플에서 페이지 배치와 이동이 FR-006~FR-011을 만족한다. 페이지 누락·중복이나 파일 페이지 수 변경이 없어야 한다.
- **SC-003**: 화면 폭 1023px·1024px의 경계에서 FR-016의 보기 제한과 현재 페이지 유지가 동작하고, 패널을 여닫아도 보기 방식이 바뀌지 않는다.
- **SC-004**: 파일 불러오기·페이지 표시 실패, 재시도, 빠른 연속 이동과 슬라이더 드래그를 검증하고 최종 본문과 위치 정보가 마지막 유효 선택과 일치한다.
- **SC-005**: 키보드만으로 탐색·보기 전환·크기 조절·패널 열기·닫기를 수행하고 포커스 복원을 확인한다. 320px 화면 폭과 브라우저 200% 확대에서도 조작부를 사용할 수 있다.
- **SC-006**: 라이트·다크 모드에서 Reader 조작부와 함께 읽기 패널을 사용할 수 있다. 넓은 화면의 패널 구분선은 키보드와 포인터로 조절할 수 있고, 목차 패널에는 임의 항목이 없어야 하며 미연결 버튼은 상태를 바꾸지 않아야 한다.
